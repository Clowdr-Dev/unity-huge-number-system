- Integration, arithmetic, formatting, persistence, and Inspector examples; API and verification references; contribution instructions.
- `scripts/verify.ps1` to run EditMode and PlayMode suites with fresh logs, XML results, a JSON summary, timeouts, and a meaningful exit code.
